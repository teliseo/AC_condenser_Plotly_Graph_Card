This code in *ac_condenser_plotly_card.yaml* is custom YAML (with much embedded
Javascript) code for a [Plotly Graph
Card](https://github.com/dbuezas/lovelace-plotly-graph-card) in [Home
Assistant](https://www.home-assistant.io/). It plots power data over time
collected from a [Shelly EM Gen3 50A Smart Energy
Meter](https://us.shelly.com/products/shelly-em-gen3-50a) connected to my air
conditioning condenser unit. The Shelly device is connected to two current
transformers (CTs). The first measures all 240 VAC power to the condenser, which
includes the compressor motor, the fan, and the crankcase heater, while the
second measures the power energizing the 24 VAC solenoid that switches the
compressor into high (stage 2) mode.

This should be easy to adapt to visualizing similar dense data sets where you
want to quickly zoom to a wide range of scales. Use it to define the code for
the card on a panel-layout view on a dashboard with no other views. This will
allow resizing without constraints.

In addition to the two Shelly sensors, this also plots the approximate nearby
outdoor temperature obtained from the default *Weather* integration. However,
the *Weather* integration doesn’t store temperature as a separate measurement
sensor, so I’ve included *outdoor_temperature_sensor.yaml* to create that. You
may also backfill historical data by running *backfill_outdoor_temperature.sql*
using *sqlite3* against the Home Assistant database (with HA stopped, of
course). Unless you’ve set Recorder’s *purge_keep_days* (or have set
*auto_purge: false*, as I have, to keep detail forever), the backfill script
will only retrieve the last 10 days of history. However, once new temperatures
are being tracked as a measurement sensor, they’ll be saved forever in
hourly-averaged form for measurements older than *purge_keep_days*.

I was surprised by the amount of customization needed to work around the
limitations, missing features, and non-ideal defaults of Plotly Graph Card and
[Plotly](https://plotly.com/javascript/) itself, to get things to look and work
exactly the way I wanted. This code is based on running with Plotly Graph Card
v3.3.5, which hasn’t been updated since 2024-09, and has significant
improvements still pending in pull requests and forks.

with me (a human).
